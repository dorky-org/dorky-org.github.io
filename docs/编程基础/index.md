# 编程基础

具身智能编程部分的完整整理：从 Linux 命令行、Python、C++，一路到 ROS 2、仿真、深度学习、真机部署。

和数学部分同一个取舍标准——**"对具身智能是否有用"**，不是"面试考不考"。**按完全没写过代码来排**，每一行只用到它上面行的知识。

区别在于，这条线上的每一行都要真的写出来跑通：

- **跑通**：官方示例在你自己的机器上从零跑起来，包括装环境那一步
- **改坏再修好**：故意改错一处，看它怎么报错，再自己修回去
- **写下来**：用自己的话写一篇笔记，讲清楚它解决什么问题、坑在哪
