# 具身智能编程学习路径

一张按顺序编号的表，共 110 行。**从第 1 行开始，做完一行做下一行。**

这条路**按"完全没写过代码"来排**，不假设任何已有基础。顺序经过依赖检查，标准比数学路径更严：

> **每一行只用到它上面行的知识——包括编程语言本身。** 第 N 行出现的代码，用到的语法、库、工具，全部在前面的行里讲过。不会出现"用还没学的语言写还没学的库"这种事。

和数学路径不同的是，这条线上的每一行都要**打开电脑真的写出来跑通**。看完视频不算做完，标准见文末「怎么算做完一行」。

## 表格说明

- **难度**：★ 到 ★★★★★。★★ 以下是"照着文档做一遍就会"，★★★★ 以上要反复返工。
- **重要**：**P0** 不学就卡死，后面直接做不下去；**P1** 重要，决定工程能力上限；**P2** 按需，用到再补。
- **时间紧张时的最小路径**：只做 P0，约 1152 小时；P0 加 P1 约 1600 小时。
- 时长按**零基础从头学**估算，含动手时间，不是视频时长。

## 阶段六：C++ 入门（27 到 33 行，122 小时）

## 怎么算做完一行

这条路最大的陷阱是**看完视频就以为学会了**。每一行的完成标准统一按下面三条判定：

- **跑通**：官方示例或教程代码在你自己的机器上从零跑起来，包括装环境那一步
- **改坏再修好**：故意改错一处（改类型、删一行、换参数），看它怎么报错，再自己修回去——**报错信息认得出来，这一行才算过**
- **写下来**：用自己的话写一篇笔记，讲清楚它解决什么问题、坑在哪。写不出来说明没学会

第三条不是形式主义。**能把一个东西讲清楚，和能跑通它，中间差着一整个理解的距离。**

另外，每个阶段末尾带「练手」字样的行（第 17、38、63、68、79 行）不要跳。**它们是把前面零散知识点粘起来的胶水**，跳过去的话，学到的东西会一直是散的。
